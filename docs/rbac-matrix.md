## قواعد سراسری

1. **Scope:** BM/CM/REC/DOC فقط دادهٔ شعبه یا کلینیک مجاز را می‌بینند مگر CEO/OPS باز کند.
2. **Audit:** هر تغییر حساس (قرارداد، مالی، دسترسی) در لاگ فعالیت ثبت شود.
3. **Separation:** مشاور فروش به تسویه پزشک/کلینیک دسترسی ندارد؛ مالی به ویرایش کمپین دسترسی ندارد.
4. **Patient:** فقط پرونده و نوبت و قرارداد خود؛ بدون دید شبکه‌ای.
5. **Future countries:** نقش‌ها ثابت می‌مانند؛ scope جغرافیایی به Country/Province اضافه می‌شود.

## گروه منوی پیشنهادی ERP

```
اجرایی          → داشبورد
فروش و CRM      → لید، تماس، قیف، قرارداد فروش
عملیات کلینیک   → نوبت، بیمار، پزشک، کلینیک
بازاریابی       → کمپین، محتوا، سوشال
مالی            → اقساط، دریافت/پرداخت، تسویه، پورسانت
منابع انسانی    → پرسنل، حضور، حقوق
پشتیبانی        → تیکت‌ها
سیستم           → کاربران، تنظیمات، لاگ
```

منوی هر نقش زیرمجموعهٔ همین گروه‌هاست (نه لیست تخت ۱۸ نقشی).
